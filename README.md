# Shepherd's Desk · 목자의 책상

성도 한 사람을 기억하는, 목회자의 책상.
교구 목회자가 직접 만들고 직접 쓰는 무료 목양 도구입니다. 심방, 돌봄, 새가족, 문자, 일정을 한 화면에 모았습니다.

- 홈페이지: https://YOUR-ID.github.io/shepherds-desk/
- 설치 도움말: https://bear4jesus.github.io/shepherds-desk/install.html

## 할 수 있는 일

- **오늘**: 생일, 돌봄할 분, 일정, 할 일, 출근·퇴근 점검
- **돌봄**: 생일(음력 포함), 결혼기념일, 장례·입원·이사 뒤 후속 연락, 어르신 안부, 오래 못 뵌 가정
- **새가족**: 환영 전화부터 정착 확인까지 단계별 기한과 문자
- **문자**: 상황별 문구 100여 개, 직분에 맞는 호칭, 맥에서는 메시지 앱으로 차례대로 보내기
- **성도·심방**: 교회 명단 엑셀 불러오기, 심방 기록과 기도제목, 사랑방 심방 함께 기록
- **말씀**: 암송 연습, 상황별 말씀을 엑셀로 불러오고 내보내기

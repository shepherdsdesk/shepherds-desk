🙋 기다려요 기능 노선마다 정합니다 · 운전 안전을 위해 필요하면 줄이거나 끄세요

  • 끄기: 성도님 화면에서 ‘기다려요’ 버튼이 사라지고 인원도 세지 않습니다.
  • 정류장에서만: 정류장 근처에서만 누를 수 있습니다. 기사님 화면에는 정류장별 인원만 나옵니다 (길 중간 정차 없음).
  • 어디서나: 길에서도 누를 수 있고, 기사님 지도에 주황 점으로 위치가 나옵니다.
  • 어디서나일 때 길에서는 노선 줄에서 고른 거리(30·50·100m) 안에서만 받습니다. 노선 줄이 아직 없는 노선은 정류장에서만 받습니다.
  • 정류장 자동 알림: 동의한 성도님이 앱을 연 채 정류장에 1분 이상 계시면 버튼을 누르지 않아도 1명으로 알려집니다. 이름·위치는 저장하지 않고 인원 숫자만 알립니다.

정류장 위치 · 도착 반경 버스가 이 원 안에 들어오면 ‘도착’으로 보고 알림을 보냅니다

‘지도에서 위치 고르기’를 누른 뒤 지도에서 버스가 실제로 서는 곳(예: 교회 입구 도로)을 누르세요. 교회처럼 넓은 곳은 반경을 120~150m로 두면 입구에만 와도 도착 알림이 갑니다. 저장하면 성도님·드라이버·TV 화면에 바로 반영됩니다.

노선 줄 성도님·TV 지도에 그려지는 버스 길. 줄이 있으면 도착 시간도 실제 길을 따라 계산합니다

운행 기록에서 가져오기

드라이버가 운행하면 회차마다 지나간 길이 자동으로 기록됩니다. 길을 바르게 다녀온 회차를 골라 ‘지도에서 보기’로 확인한 뒤 ‘노선 줄로 저장’을 누르세요. 길이 바뀌면 새 운행 기록으로 다시 저장하면 됩니다. 지우면 예전처럼 줄 없이 동작합니다.

지도 설정 카카오 지도 키를 넣으면 성도님·드라이버·관리자·TV 화면 지도가 카카오맵으로 바뀝니다

카카오 디벨로퍼스 앱의 JavaScript 키를 넣어 주세요. 그 키의 JavaScript SDK 도메인에 https://shepherdsdesk.github.io를 등록하고, 카카오맵 사용 설정을 켜야 지도가 열립니다. 키가 맞지 않으면 자동으로 OpenStreetMap으로 보입니다. 저장 뒤 각 화면을 새로고침하면 바뀝니다.

관리자 추가 구글 계정 또는 아이디

아이디로 추가할 때 (처음 한 번만)
  1. Firebase 콘솔 → Authentication → 로그인 방법에서 이메일/비밀번호를 사용 설정합니다.
  2. Authentication → 설정 → 사용자 작업에서 ‘생성(가입) 사용 설정’을 끕니다. (아무나 계정을 만들지 못하게 · 꼭 해 주세요)
  3. Authentication → 사용자 → 사용자 추가에서 이메일 칸에 아이디@hccshuttle.app (예: shuttle01@hccshuttle.app), 비밀번호를 넣어 만듭니다.
  4. 그분은 관리자 화면에서 아이디(예: shuttle01)와 비밀번호로 로그인합니다.

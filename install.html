맥 · 1

맥 앱 설치하기

macOS 11 이상, 애플 실리콘(M1 이후) 맥에서 쓸 수 있습니다. 내 맥이 애플 실리콘인지는 화면 왼쪽 위 Apple 메뉴 → 이 Mac에 관하여에서 "칩"이 Apple M으로 시작하는지 보면 됩니다.

  1. 맥용 내려받기를 눌러 ShepherdsDesk-AppleSilicon.dmg를 받습니다.다운로드 폴더에 저장됩니다. 약 100MB입니다.
  2. 받은 DMG 파일을 두 번 눌러 엽니다.
  3. 열린 창에서 Shepherd's Desk 아이콘을 옆의 Applications(응용 프로그램) 폴더로 끌어 놓습니다.
  4. Finder 왼쪽 목록에서 Shepherd's Desk 디스크 옆의 ⏏ 단추를 눌러 꺼냅니다. DMG 파일은 지워도 됩니다.
  5. 응용 프로그램 폴더 또는 Launchpad에서 Shepherd's Desk를 엽니다. 확인 창이 뜨면 다음 단계를 따라 주세요.
새 버전이 나오면 같은 방법으로 덮어쓰면 됩니다. 성도 정보와 설정은 그대로 남습니다.

맥 · 2

"Apple은 'Shepherd's Desk'에 악성 코드가 없음을 확인할 수 없습니다"

Shepherd's Desk는 무료로 나누는 프로그램이라 애플의 유료 개발자 인증을 받지 않았습니다. 그래서 처음 한 번만 직접 허락해 주셔야 합니다. 한 번 열고 나면 다음부터는 묻지 않습니다.

'Shepherd's Desk'이(가) 열리지 않음

Apple은 'Shepherd's Desk'에 Mac을 손상시키거나 개인정보를 침해할 수 있는 악성 코드가 없음을 확인할 수 없습니다.

휴지통으로 이동완료

그림은 이해를 돕기 위해 다시 그린 것입니다. macOS 버전에 따라 문구가 조금 다를 수 있습니다.

  1. 확인 창에서 완료를 누릅니다.휴지통으로 이동은 누르지 마세요.
  2. Apple 메뉴 → 시스템 설정 → 개인정보 보호 및 보안으로 갑니다.
  3. 아래로 내려 "보안" 칸에 있는 "Shepherd's Desk"이(가) 차단되었습니다 옆의 그래도 열기를 누릅니다.
  4. 맥 암호(또는 Touch ID)를 넣고, 다시 뜨는 창에서 열기를 누릅니다.

맥 · 문제 해결

"'Shepherd's Desk'이(가) 손상되었기 때문에 열 수 없습니다"

파일이 실제로 망가진 것이 아니라, 인터넷에서 받은 파일에 붙는 표시 때문에 나오는 경우가 대부분입니다. 휴지통으로 옮기지 마시고 아래 명령어로 표시를 지워 주세요.

  1. 먼저 Shepherd's Desk를 응용 프로그램 폴더로 옮겼는지 확인합니다.
  2. 응용 프로그램 → 유틸리티 → 터미널을 엽니다. (Spotlight에서 "터미널"을 찾아도 됩니다.)
  3. 아래 명령어를 복사해 터미널에 붙여 넣고 return을 누릅니다. 아무 글자도 나오지 않으면 정상입니다.
xattr -dr com.apple.quarantine "/Applications/Shepherd's Desk.app"
  1. 다시 Shepherd's Desk를 엽니다. 확인 창이 뜨면 처음 여는 방법대로 허락해 주세요.

맥 · 3

알림과 메시지 앱 권한 허용하기

일정과 돌봄을 알려 드리고, 인사 문자를 메시지 앱으로 차례대로 보내려면 두 가지 허락이 필요합니다.

  1. 알림: 처음 알림이 올 때 뜨는 창에서 허용을 누릅니다.놓쳤다면 시스템 설정 → 알림 → Shepherd's Desk에서 알림 허용을 켭니다.
  2. 메시지 앱: 문자 화면에서 처음 [메시지 앱으로 보내기]를 누르면 "'Shepherd's Desk'이(가) 'Messages'을(를) 제어하려고 합니다"라고 묻습니다. 확인을 누릅니다.놓쳤다면 시스템 설정 → 개인정보 보호 및 보안 → 자동화에서 Shepherd's Desk 아래 Messages를 켭니다.
  3. 아이폰이 아닌 번호에도 일반 문자로 보내려면 아이폰의 설정 → 앱 → 메시지 → 문자 메시지 전달에서 이 맥을 켜 둡니다.

웹 · 1

웹 버전 설치하기 (아이폰 · 아이패드 · 윈도우)

웹 버전은 목사님의 구글 계정 안에서 돌아갑니다. 구글 앱스크립트 프로젝트의 사본을 내 계정에 만들고, 나만 여는 웹 주소로 배포하면 됩니다. 컴퓨터에서 한 번만 하시면 됩니다. 10분 정도 걸립니다.

교회에서 받은 구글 계정(학교·회사용 Workspace)은 관리자가 막아 두었을 수 있습니다. 개인 Gmail 계정을 권합니다.
  1. 컴퓨터 브라우저로 구글 계정에 로그인한 뒤, 웹 버전 사본 링크를 엽니다.코드가 보이는 편집기 화면이 먼저 열립니다. 읽기 전용이라 고칠 수 없는 것이 정상입니다.
  2. 화면 왼쪽 끝 세로 아이콘 줄의 맨 위 ⓘ(개요)를 누릅니다. 개요 화면 오른쪽 위의 겹친 종이 모양 아이콘(사본 만들기)을 누릅니다."Shepherd's Desk 웹의 사본"이라는 새 프로젝트가 내 드라이브에 생깁니다. 이제부터는 이 사본에서 작업합니다.
  3. 위쪽 이름을 눌러 Shepherd's Desk로 바꿉니다. (선택)
  4. 왼쪽 <> 편집기에서 Code.gs를 엽니다. 위쪽 함수 목록에서 setup을 고르고 ▷ 실행을 누릅니다.
  5. "승인 필요" 창이 뜨면 권한 검토 → 내 구글 계정을 고릅니다. 경고 화면이 나오면 다음 단계를 따라 주세요.
  6. 아래 실행 로그에 "준비 완료"와 맥 앱 연결 키가 나오면 성공입니다. 연결 키는 맥과 연결할 때 씁니다.

이제 나만 여는 웹 주소를 만듭니다. → 배포하기

웹 · 문제 해결

"Google에서 확인하지 않은 앱"

내가 방금 만든 사본을 내 계정이 처음 실행할 때 나오는 경고입니다. 이 프로젝트는 목사님 계정의 드라이브에 파일 하나를 만들고 읽는 권한만 씁니다.

Google에서 확인하지 않은 앱

앱에서 Google 계정의 민감한 정보에 대한 액세스를 요청합니다. 개발자가 Google에 앱 확인을 요청할 때까지 앱을 사용하지 마세요.

  1. 왼쪽 아래 고급을 누릅니다.

웹 · 2

나만 여는 웹 주소 만들기 (배포)

  1. 오른쪽 위 배포 → 새 배포를 누릅니다.
  2. "유형 선택" 옆 톱니바퀴 ⚙ → 웹 앱을 고릅니다.
  3. 설명에 "휴대폰"이라고 적고, 다음 사용자 인증 정보로 실행: 나, 액세스 권한이 있는 사용자: 나만으로 둡니다.
  4. 배포를 누르고, 나오는 웹 앱 URL(/exec로 끝나는 주소)을 복사해 둡니다.
  5. 그 주소를 브라우저에서 열어 오늘 화면이 나오면 성공입니다.
새 버전으로 파일을 바꾼 뒤에는 배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포를 눌러야 바뀐 내용이 웹 주소에 반영됩니다. 주소는 그대로입니다.

이제 휴대폰에 앱처럼 붙여 둡니다. → 홈 화면에 추가

아이폰·아이패드 홈 화면에 추가하기

  2. 사파리에서 앱을 만든 같은 구글 계정으로 로그인되어 있어야 합니다.

웹 · 문제 해결

"이 페이지는 주인만 열 수 있습니다"

웹 주소는 앱을 만든 계정에서만 열리도록 되어 있습니다. 이 화면이 나오면 브라우저에 다른 구글 계정이 로그인되어 있는 경우가 대부분입니다.

  1. 브라우저 오른쪽 위 프로필에서 지금 로그인한 계정을 확인합니다.
  2. 여러 계정이 로그인되어 있다면, 시크릿 창(개인 정보 보호 브라우징)을 열고 앱을 만든 계정으로만 로그인한 뒤 주소를 엽니다.
  3. 그래도 같다면 배포 설정에서 "다음 사용자 인증 정보로 실행"이 나인지 확인합니다.

웹 · 문제 해결

빨간 안내줄 "설치가 덜 끝났습니다"

앱스크립트의 파일 가운데 하나가 비었거나, 붙여 넣다가 잘렸을 때 나옵니다. 안내줄에 어느 파일인지 이름이 적혀 있습니다.

  1. 가장 쉬운 방법은 사본 만들기를 처음부터 다시 하는 것입니다.
  2. 파일을 직접 고칠 때는 웹 버전 ZIP을 받아 풀고, 설치도우미.html을 브라우저로 엽니다. 텍스트 편집기로 열면 한글이 깨집니다.
  3. 앱스크립트에서 그 파일을 열고 ⌘A로 지운 뒤, 설치도우미의 [복사] → ⌘V → ⌘S 순서로 붙여 넣습니다.
  4. 배포 관리 → 새 버전으로 다시 배포합니다.

맥 + 웹

맥과 휴대폰을 함께 쓰기

맥 앱이 목사님의 웹 버전(구글 드라이브)과 내용을 주고받게 합니다. 맥 앱은 구글에 로그인할 수 없어서, 연결 키로 들어가는 배포를 하나 더 만듭니다.

  1. 앱스크립트에서 배포 → 새 배포 → 웹 앱을 고릅니다.
  2. 설명은 "맥 앱 연결", 실행은 나, 액세스 권한은 모든 사용자로 두고 배포합니다. 나온 주소를 복사합니다."모든 사용자"여도 연결 키가 없으면 아무것도 열리지 않습니다. 이 선택지가 없다면 교회 계정이라 막힌 것이니 개인 Gmail로 다시 만들어 주세요.
  3. 연결 키를 잊었다면 Code.gs에서 setup을 다시 실행합니다. 같은 키가 로그에 나옵니다.
  4. 맥 앱 설정 → 기기 동기화에 연결 주소와 연결 키를 넣고, "3분마다, 그리고 고칠 때마다 동기화"를 켠 뒤 지금 동기화를 누릅니다.
  5. 초록색 연결됨이 보이면 성공입니다. 휴대폰의 웹 화면을 새로고침하면 같은 내용이 보입니다.
맥 앱에 이미 입력해 둔 성도와 메모가 있다면 맥을 먼저 연결해서 드라이브에 올리세요. 파일을 고친 뒤에는 두 배포 모두 새 버전으로 올려야 맥과 휴대폰이 같은 코드로 돌아갑니다.

처음 설정

교회 정보, 성도 명단, 말씀 본문 넣기

맥 앱과 웹 버전 모두 같은 순서입니다. 한 번만 해 두면 오늘 화면과 돌봄 알림판, 문자가 바로 채워집니다.

  1. 설정 → 돌봄에서 교회 이름, 부서, 사역자 이름, 문자 서명을 넣습니다.서명을 비워 두면 "교회 부서 사역자 드림"으로 들어갑니다.
  2. 성도·심방 → 명단 가져오기로 교회 성도 명단 엑셀(또는 CSV)을 올립니다.이름, 직분, 생년월일, 전화번호, 사랑방 칸을 알아서 찾습니다. 다시 올려도 같은 분은 겹치지 않습니다. [샘플 받기]로 양식을 볼 수 있습니다.
  3. 말씀 → 엑셀로 내보내기를 누릅니다. 암송 말씀과 상황별 말씀의 구절 주소가 담긴 표가 저장됩니다.같은 표를 말씀 양식 엑셀로 바로 받을 수도 있습니다.
  4. 엑셀에서 본문 칸에 쓰시는 성경 번역의 본문을 넣고 저장합니다.칸 이름(구분 · 묶음 · 태그 · 주소 · 본문 · 주제)은 바꾸지 마세요. 새 구절은 줄을 더해 적으면 됩니다.
  5. 말씀 → 엑셀 불러오기로 그 파일을 고르고 불러오기를 누릅니다.
프로그램에는 성경 본문이 들어 있지 않습니다. 번역본마다 저작권이 있어서, 본문은 목사님이 쓰시는 성경에서 직접 넣도록 했습니다.
